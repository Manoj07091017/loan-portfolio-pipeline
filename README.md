# Loan Portfolio Data Pipeline

End-to-end ELT pipeline for loan portfolio data: Python → S3 → Snowflake → dbt, orchestrated with Airflow and tested with GitHub Actions.

**Status:** Phase 1 — ingestion complete (2.26M loans, 139 monthly partitions in S3).

## Stack
Python 3.12 (uv) · AWS S3 · Snowflake · dbt · Airflow · GitHub Actions
